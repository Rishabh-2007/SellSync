SELLSYNC - LOCAL START GUIDE (WINDOWS)

1. Extract the entire ZIP folder first. Do not run it from inside the ZIP preview.
2. Install Python 3.10+ and Node.js 18+ if they are not already installed.
3. Double-click run.bat.
4. The first run may take several minutes while Python packages are installed.
5. Your browser should open http://127.0.0.1:5173 automatically.
6. Keep the two SellSync terminal windows open while using the app.
7. To stop SellSync, close the backend and frontend terminal windows.

API docs: http://127.0.0.1:8000/docs

IMPORTANT:
A browser cannot start a Python API server by opening index.html directly. This is a full-stack React + FastAPI application, so run.bat is the one-click launcher. It starts both parts and opens the website in your browser.

Integrations are demo/simulated. Do not enter real customer or payment data.
